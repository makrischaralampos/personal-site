I wanted a personal site that actually looked like the thing I care about
building, instead of a generic template with my name swapped in. So instead
of "Home / About / Projects / Contact," this site is framed as a character
sheet: stats instead of a skills list, quests instead of a project list,
this Chronicle instead of a blog.

## The stack, briefly

Astro, hand-written CSS, self-hosted pixel fonts, zero trackers. No CMS,
no analytics script, no cookie banner — because there's nothing here that
needs one. Content lives as Markdown/MDX files in the same git repo as the
code, versioned like everything else I build.

## Why this matters to me

"Indie, ethical, fun" isn't just marketing language I attach to game dev —
it's the filter I want applied to everything I ship, including this site
that's supposed to represent this philosophy. A portfolio site stuffed with
tracking pixels and dark-pattern popups would be a strange way to introduce
someone to that idea.
